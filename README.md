# Real-Time Chat Application

A real-time chat application built using React, Vite, Socket.IO, Express, and Node.js.

## Features
- Real-time messaging
- Multiple users
- Username support
- Sent and received message UI
- Enter key support

## Tech Stack
- React
- Vite
- Socket.IO
- Express
- Node.js

## Run Frontend

npm run dev

## Run Backend

cd server
node server.js

How It Works

When a user sends a message from the frontend, Socket.IO transmits the message to the server instantly. The server then broadcasts the message to all connected users in real time. This creates a smooth chatting experience without needing to refresh the page.
