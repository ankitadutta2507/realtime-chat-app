# Real-Time Chat Application

A real-time chat application built using React, Vite, Socket.IO, Express, and Node.js.

## Features
- Real-time messaging
- Multiple users
- Username support
- Sent and received message UI
- Enter key support

## Tech Stack
- React
- Vite
- Socket.IO
- Express
- Node.js

## Run Frontend

npm run dev

## Run Backend

cd server
node server.js
